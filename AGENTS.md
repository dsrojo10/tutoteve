# TutoTeVe

1. Lee `SPEC.md` antes de cambiar el proyecto.
2. Mantén la simplicidad extrema: JavaScript nativo y el mínimo de dependencias.
3. La accesibilidad es prioritaria; la interfaz debe ser clara y operable con teclado/control remoto.
4. No sobreingenierices ni agregues funcionalidades fuera del experimento definido.
5. Antes de entregar, ejecuta las pruebas disponibles, `npm run build` y `git diff --check` cuando haya repositorio Git.
6. No hagas commits salvo que se solicite explícitamente.
